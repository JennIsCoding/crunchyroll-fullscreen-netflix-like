# Crunchyroll Fullscreen (Netflix-like)

Extensão do Chrome que deixa o player do Crunchyroll ocupando a janela toda, sem barras e menus, igual à Netflix.

## Instalar

1. Abra `chrome://extensions`
2. Ligue o **Modo do desenvolvedor** (canto superior direito)
3. Clique em **Carregar sem compactação** e escolha esta pasta

## Usar

- Liga sozinha ao abrir um episódio (`/watch/...`)
- Tecla **T** ou clique no ícone da extensão liga/desliga (a escolha fica salva)
- O botão de tela cheia do próprio player continua funcionando
